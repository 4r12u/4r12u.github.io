This write-up covers the PicoCTF 2026 challenges I solved with **EHC_Loi_Yeu_Kho_Noi_Pl2s**. It mainly focuses on reverse engineering, using IDA Pro, Ghidra, Detect It Easy, Scapy/Wireshark, and LLM-assisted analysis.

## Gatekeeper

The program expects a number greater than 999 and less than 9999. Because it uses `atoi`, an ASCII string can be converted into a number. Testing with `abc` produces an output containing the repeated string `ftc_oc_ip`. Removing the repeated characters leaves:

```text
}847d936b_999_TG_xeh_tigid_3{FTCocip
```

Reversing each chunk gives the flag:

```text
picoCTF{3_digit_hex_GT_999_b639d748}
```

## Hidden Cipher 1

The program prints an encoded flag:

```text
235a201d70201548251358110c552f135409
```

After inspecting the binary in IDA, XORing the encoded text with the recovered value gives:

```text
picoCTF{xor_unpack_4nalys1s_530ca742}
```

## Hidden Cipher 2

The service first asks a simple math question and then prints an encoded flag. The decompiled encoder multiplies every flag byte by `a2`:

```c
for (i = 0; flag[i]; ++i) {
    printf("%d", a2 * flag[i]);
}
```

The known prefix `picoCTF{` shows that the multiplier is 15. Dividing every value by 15 and converting the results to ASCII recovers:

```text
picoCTF{m4th_b3h1nd_c1ph3r_4a3b2ccf}
```

## The Add/On Trap

The challenge is a Firefox `.xpi` extension. Renaming it to `.zip` exposes `main.js`, which contains a Base64 key and a Fernet-encrypted webhook URL. The key is:

```text
cGljb0NURnt5b3UncmUgb24gdGhlIHJpZ2h0IHRyYX0=
```

Decrypting the webhook with Python's `cryptography.fernet` module reveals the flag:

```text
picoCTF{Us3_4dd/0ns_v3ry_c4r3fully1}
```

## Silent Stream

The challenge provides a PCAP and an encoder that sends each byte as `(byte + 42) % 256`. The useful TCP payloads are on port 9000. Extracting the raw bytes with Scapy and subtracting 42 reconstructs a JPEG file:

```python
from scapy.all import Raw, TCP, rdpcap

packets = rdpcap("packets.pcap")
encoded = bytearray()
for packet in packets:
    if Raw in packet and TCP in packet and packet[TCP].dport == 9000:
        encoded.extend(packet[Raw].load)

decoded = bytes((byte - 42) % 256 for byte in encoded)
open("flag.jpeg", "wb").write(decoded)
```

The recovered flag is:

```text
picoCTF{tr4ck_th3_tr4ff1c_8d66583c}
```

## Secure Password Database

The password is generated by XORing an obfuscated byte array with `0xAA` before hashing it:

```c
for (i = 0; obf_bytes[i]; ++i)
    password[i] = obf_bytes[i] ^ 0xAA;
```

Recovering the bytes and reproducing the hash function produces the expected input and the flag:

```text
picoCTF{d0nt_trust_us3rs}
```
