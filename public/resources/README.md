# Archive resources

Keep files that belong to an archive entry in a folder named after the post
slug, for example `public/resources/pe-loader-notes/`.

Link code, research papers, datasets, or study slides from the Markdown post:

```md
[Download the slides](/resources/pe-loader-notes/slides.pdf)
```

The archive page remains the timeline for the post; this folder holds the
supporting files attached to that entry.
